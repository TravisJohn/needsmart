# NeedSmart

A grocery assistant that turns a household's receipts into next week's shopping plan. It learns each household's buying rhythm, matches it to this week's specials, offers cheaper swaps only where the household is happy to switch brands, and shows what was really saved.

- **Story** (`index.html`): the product vision, the premise study, how it works, gaps with proposed fixes, and the plan.
- **Try me** (`app.html`): an interactive demo for desktop and phone, with three demo households, weekly plans, need rhythms, savings and insights, and an assistant.

All data on both pages is synthetic. No real receipts, prices or customers are used.

Live site: https://travisjohn.github.io/needsmart/

## Updating

The pages are built in the main project under `concept/`. To refresh this site, copy `needsmart-vision.html` to `index.html` and `needsmart-app.html` to `app.html`, then commit and push.
